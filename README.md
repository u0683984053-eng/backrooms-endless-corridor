# 《后室：无尽回廊》Backrooms: Endless Corridor

> 一款以后室（The Backrooms）Fandom 版世界观为核心的**开放世界生存探索游戏**。
> 你不是在"通关"后室，而是在"居住"在后室里。

**当前状态**：设计阶段（GDD v0.2）+ M0 技术原型（可玩，32 个层级，含无限世界分块生成）。

## 无限世界（v0.3 原型核心）

- **43 个无边界层级**（Level 0-22/31/33-97/150/169/231/3999/555/666/799/922/999/-1 等）采用 Minecraft 式 16×16 分块生成：走到哪里生成到哪里，确定性种子保证同存档重进世界一致。
- **12 个有限层级**（0.1/5/8/28/100/188/205/400/404/976/枢纽/!）边界一律为**墙**而非虚空。
- 拓扑按 F 版设定差异化：房间迷宫（房间+柱子）/ 城市街区 / 仓库大厅 / 旅馆走廊 / 田野 / 洞穴隧道 / 地铁隧道（Level 169）/ 跑道 / 无尽楼梯间。
- 无限层 HUD 出口罗盘（8 向箭头+距离）与小地图出口箭头，避免迷失。
- 场景锚点（setPieces）在无限层同样确定性生成——字条、尸体、怪异房间真实可触，含 5 个"看到即理智归零"的致命场景（暗红微光警示）。
- 存档只记取走/击杀集合，瓦片重放重建；explored 环形淘汰控制体积；chunk 缓存上限 128（确定性重建）。

## 系统一览（v0.3 原型）

- **75 个层级**（61 无限 + 14 有限）· **16 种实体**（含管道潜伏者/残缺者/蒸汽幻影）· **12 种物品**（含手枪/弹药/无人机）· **29 个成就** · **19 种天赋**（攻击/防御/空间/探测/生存五类）
- 属性波动（90-110 上限）+ 40% 概率随机天赋；野性层级 30% 概率天赋变异
- 特殊机制：无尽追击（!）/高温灼烧（666）/幻影噪音（16/169）/黑暗脉冲（21）/森林低语（14）/双色切换（34）/上课铃（118）/心电监护（170）/时间异常/重力异常

## 核心设计决策（v0.2）

1. **三层内容模型**：A 手工核心层（30-40，博物馆级）+ B 策展生成层（200-300）+ C 野性生成层（无限）——替代"4000 手作层级"。
2. **Set Piece 铁律**：程序化只生成背景板，恐怖由手作场景锚点负责。
3. **死亡 + Codex 闭环**：永久死亡；行记跨轮持久——输掉身体，赢得知识。
4. **确定性生成 + 世界持久化**：`层级ID + 种子 → 布局`，存档只存 delta。
5. **理智系统**：四阶段（平静/不安/恐惧/崩溃），幻觉内容库是正式内容品类。
6. **三通道感知**：光线/声音/视线——潜行玩法的基础。
7. **单人 1.0** + UGC 四阶段（只读导入 → 编辑器 v1/v2 → 策展掉落）。
8. **合规先行**：CC BY-SA 署名策略 + 游戏内文档原创改写。
