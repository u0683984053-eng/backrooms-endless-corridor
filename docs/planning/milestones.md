# 《后室：无尽回廊》里程碑与预算（Milestones）

> 版本：v0.2 ｜ 状态：草案 ｜ 依据：`docs/gdd-v0.2.md` §7、§8；`docs/design-review.md` P2-2（EA 提前）
> 总节奏：**M0 原型 → M1 EA 抢先体验 → M2 内容飞轮 → M3 1.0 发布**；单人 1.0、UGC 四阶段渐进、8 人团队 × 48 个月。

## 1. 总览

| 阶段 | 时间 | 核心交付 | 团队投入 | 关口 |
|------|------|---------|---------|------|
| M0 原型 | 0-6 月 | 核心循环 + DNA 工具 + 3 个 A 类层 | 48 人月 | Go/No-Go |
| M1 EA | 18-24 月 | EA：100-150 层 + 全部核心系统 + Codex + 社区只读导入 | 144-192 人月 | EA 上线（现金流） |
| M2 | 30-36 月 | 300-500 层 + 编辑器 v1 + 月度策展掉落 | 96-144 人月（新增） | 内容飞轮启动 |
| M3 1.0 | 40-48 月 | A40 + B250 + C 无限 + 创意工坊 + 陈列室 | 96-144 人月（新增） | 1.0 发布 |

## 2. M0 原型（0-6 月）——验证"玩法成立"

### 2.1 交付清单

- [ ] 可玩原型：Level 0 完整循环（进入→管理三态→遭遇实体→卡出）
- [ ] 回合经济学 + 三通道感知模型最小实现
- [ ] 确定性生成器（L1 拓扑 + L2 填充）+ `(层级ID, 种子, delta)` 存档原型（`proto/` 验证）
- [ ] DNA 工具 v0：schema 校验 + 参数编辑 + 单层预览
- [ ] 3 个 A 类层（Level 0 / Level 1 / Level -1）+ CI 冒烟测试（1000 种子 × 3 层，BFS 可达性）

### 2.2 验收标准（Go/No-Go）

| 指标 | 目标 |
|------|------|
| 核心循环可连续游玩 30 分钟无死锁/无存档损坏 | 通过 |
| 确定性：同种子两次生成布局 hash 一致（100/100） | 通过 |
| 冒烟测试 0 BLOCKED、重试率 < 5% | 通过 |
| 内部试玩认可"这次死亡记住了什么"（Codex 价值感 ≥ 8/10）+ 原型层目标机 ≥ 45fps | 通过 |

### 2.3 团队投入与退出条件

8 人 × 6 月 ≈ **48 人月**：主程全时（生成器/持久化）、3D/TA 1.5 人（Level 0 资产最小集 + set piece 15-30 件）、关卡 1 人、系统设计 1 人、音频 0.5 人、工具 1 人。

| 风险 | 退出/缓解 |
|------|----------|
| 回合制节奏与"沉浸恐怖"冲突 | 试玩反馈断裂 → 原型内切实时制验证，不拖入 M1 |
| 非欧/循环空间原型失败 | 只验证 `looping`；`non-euclidean` 降级 M2 后立项 |
| 确定性在 UE5 PCG 层失效 | L2 回退自研填充器（不依赖 UE5 PCG 采样） |
| **Go 条件不满足** | 停 M1 立项，先补原型短板，不带未验证循环进 EA |

## 3. M1 EA（18-24 月）——现金流 + 社区输入点

### 3.1 交付清单（EA 首发）

- [ ] Steam EA 首发：100-150 层级（A10 + B90 + C 无限生成）
- [ ] 全部核心系统：三态/理智五阶段（含幻觉内容库初版）/三通道感知/有限战斗/物品经济
- [ ] 永久死亡 + 死亡结算页 + **Codex 跨轮持久**（存档分离）；收藏陈列室最小版 + 出口图网络（Level 0 可达全部 A 类层）
- [ ] **社区只读导入**（UGC 阶段 1）：创意工坊订阅 → 服务端校验 → 加载他人层级
- [ ] P0 资产集全量（约 460 模块）+ Telemetry 埋点上线 + 合规署名页/EULA

### 3.2 验收标准（EA 上线关口）

| 指标 | 目标 |
|------|------|
| 首发 A10 全部通过人工质量评审 | 通过 |
| 冒烟测试全量回归 0 BLOCKED | 通过 |
| Codex 打开率（EA 后 2 周内测） | ≥ 60%（GDD §10） |
| 布局版本升级后旧档可迁移 + 社区导入加载成功率 | ≥ 95% |

### 3.3 团队投入与退出条件

8 人 × 18-24 月 ≈ **144-192 人月**（含 M0 已投入 48 人月，M1 新增 96-144 人月）。音频 1 人全时（Wwise 程序化管线）、工具 1 人（编辑器雏形 + CI + Telemetry）。

| 风险 | 退出/缓解 |
|------|----------|
| EA 收入不及预期 | 预算 §7 预留 60-80% 覆盖率；< 40% → 缩减 B 类产能，保 A 类与核心系统 |
| 社区导入内容安全（脚本/崩溃） | 服务端校验 + 只读加载 + 白名单；验不过暂缓 UGC 阶段 1 |
| **硬退出条件** | EA 上线 6 个月内 7 日留存 < 8% → 停止内容扩张，评估转向/止损 |

## 4. M2（30-36 月）——内容飞轮启动

### 4.1 交付清单

- [ ] 层级总量 300-500（A20 + B180-280 + C 无限）
- [ ] **编辑器 v1**（UGC 阶段 2）：DNA 参数化编辑 + 模块摆放 + set piece 放置 + 本地测试
- [ ] **月度策展掉落**：社区投票最高 C 类升级为 B 类（首个飞轮闭环）
- [ ] 非欧空间规则落地（`non-euclidean`）+ 幻觉内容库补全 + 成就系统

### 4.2 验收标准

| 指标 | 目标 |
|------|------|
| 月度策展掉落连续 3 个月按时上线 | 通过 |
| 编辑器 v1 生成 1 个可玩 B 类层 ≤ 1 人日（内部测试） | 通过 |
| 层级总数达标且冒烟测试全绿 | 通过 |

### 4.3 团队投入与退出条件

8 人 × 30-36 月累计 ≈ **240-288 人月**；M2 阶段新增约 96-144 人月。编辑器 v1 由工具/管线 1 人主导 + 主程 0.5 人支援。

| 风险 | 退出/缓解 |
|------|----------|
| 编辑器 v1 范围膨胀 | 锁死范围：只支持 B/C 类（DNA 编辑+摆放），脚本/触发器留 M3 |
| 月度策展无社区供给 | 先以官方内部"策展"填充 3 个月，验证流程再开放投票 |
| 内容产能跟不上掉落节奏 | 回退双月掉落，以质量为先 |

## 6. 内容产能表（人日/层）

| 内容类 | 数量（1.0） | 单层成本 | 总人日 | 说明 |
|--------|------------|---------|--------|------|
| A 手工核心层 | 30-40 | 20-40 人日 | 600-1600 | 全手工 + 定制 set piece + 专属音频 |
| B 策展生成层 | 200-300 | 2-5 人日 | 400-1500 | 手工调优 DNA 模板 × 程序化 + 人工抽查 |
| C 野性生成层 | 无限 | 0.1-0.5 人日 | 边际成本趋零 | 自动生成 + DNA 变异，仅需模板维护 |
| 模板维护（B/C 的 DNA 模板） | ~30 模板 | 3-5 人日/模板 | 90-150 | 模板是 B/C 的杠杆 |

> 依据 design-review P0-1：A+B 总人日 1000-3100 ≈ 4-13 人年，由 1-2 名关卡设计师 + 工具管线分摊，与 48 个月周期匹配。**C 类无限生成是规模叙事的关键——成本不在层数，而在模板质量。**

## 7. 预算粗算（国内团队）

| 项 | 估算 | 说明 |
|----|------|------|
| 人力 | 8 人 × 48 月 ≈ **800-1200 万 RMB** | 国内一线/新一线薪酬口径，含社保 |
| 发布/法务/硬件 | 另计 100-200 万 | 不含在 800-1200 万内 |
| EA 收入 + 发行商预付 | 覆盖 60-80% | EA 提前（M1）是现金流核心 |
| 缺口 | 20-40% 自筹/投资 | 需在 M1 前落实 |

- 现金流关键节点：M0 结束（Go 决策）→ M1 EA 上线（首个收入）→ M2 策展掉落（留存验证）→ M3 1.0（完整营收）；EA 收入覆盖 < 40% → 触发 §3.4 缩减策略（保 A 类与核心系统，砍 B 类扩张）。

## 8. EA 策略说明

1. **提前原因**：5 年纯内包对 7-9 人团队是极高现金流风险（design-review P2-2）；EA 同时是社区内容输入点。
2. **EA 首发口径**：100-150 层级（A10 + B90 + C 无限）+ 全部核心系统 + Codex + 社区只读导入——**不喊"4000 层级"**，口径为"手作奇迹 + 无尽生成 + 社区共创"。
3. **EA 期间策略**：月度策展掉落（M2 起）形成"社区投票 → 官方升级"飞轮；Telemetry 反馈修 DNA 模板。
4. **EA → 1.0 路径**：A10→A40、B90→B250、只读导入→编辑器 v1→v2、陈列室最小版→完整版。

## 9. 团队结构（8 人基线）

| 岗位 | 人数 | 职责 |
|------|------|------|
| 主程 | 1 | 架构/PCG（L1 生成器）/世界持久化/确定性 |
| 3D/TA | 2-3 | 资产管线（AI 建模兜底）/材质/性能优化 |
| 关卡/环境 | 1-2 | A 类层装配/B 类模板调优/策展抽查 |
| 系统设计 | 1 | 数值/三通道感知/理智系统/Codex 内容 |
| 音频 | 1 | Wwise 程序化管线/底噪合成/静默切层 |
| 工具/管线 | 1 | DNA 编辑器/CI 冒烟测试/Telemetry/Perforce |

> 8 人 = 1+3+1+1+1+1（取上限）；M0 期可 6-7 人到岗，M1 前补齐。技能互备：关卡↔工具、3D↔TA 互为 backup，缺员优先保主程 + 工具/管线。
