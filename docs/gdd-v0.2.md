## 1. 定位与范围

### 1.1 一句话定位

**一款以后室（The Backrooms）Fandom 版世界观为核心的开放世界生存探索游戏——不以通关为目标，而是让玩家在数千个层级中"存在"。**

> 核心理念不变：**你不是在"通关"后室，而是在"居住"在后室里。**

### 1.2 范围声明（v0.2 新增，明确边界）

| 事项 | 1.0 范围 | 说明 |
|------|---------|------|
| 游戏模式 | **单人沉浸式** | 恐怖在孤独中成立；多人重构技术栈，排除出 1.0 |
| 死亡模型 | **永久死亡 + 跨轮行记（Codex）** | 输掉身体，赢得知识 |
| 基地建设 | **降级为"收藏陈列室"** | 完整建造系统 → DLC/UGC |
| 联机愿景 | 仅 roadmap | "氛围性幽灵联机"远期探索 |
| 目标平台 | PC（Steam）优先，主机次之 | EA 先行 |
| 引擎 | Unreal Engine 5 | 模块化资产 + PCG + AI 辅助管线 |

### 1.3 设计哲学（保留 v1.0）

- 目标驱动 → 体验驱动
- 线性流程 → 自由探索
- 战胜挑战 → 沉浸与发现
- 明确胜利条件 → 玩家自行定义意义

## 2. 世界观设定（沿用 v1.0，浓缩）

- **核心设定**：从现实"穿模（Noclipping）"跌入只有潮湿地毯、黄色墙纸、荧光灯嗡鸣的异空间。
- **层级体系**：普通层级（整数编号）、子层级（小数编号）、隐秘层级（代号）、负数层级。
- **组织**：M.E.G.（探险者总署）作为环境叙事背景（文档、广播、据点），**不作为任务发布者**。
- **资源**：杏仁水（理智/生命）、皇家口粮（体力）、电池、手电、武器（撬棍等临时武器）。
- **玩家身份**：普通人，无特殊能力。游戏内文档一律原创改写（合规要求，见 §10）。

## 3. 核心玩法系统

### 3.1 总体游戏循环（v0.2 补全闭环）

```
进入层级 → 观察/记录 → 管理三态(生命/理智/体力) → 遭遇实体与事件
   ↑                                                        ↓
   └──── 卡出(Noclipping) 进入下一层级 ← 寻找故障点/通道 ← 收集资源与文档
```

**回合经济学**（原型即验证）：每个行动 = 1 回合；实体每回合行动一次；生存状态每回合结算。
**张力弧线**：资源（理智恢复品、体力）稀缺性驱动"继续探索 vs 撤回安全层"的决策——安全层（Level 1/11/37/3999）是锚点，危险层是收益与风险。

### 3.2 生存三态（v0.2 给出数值基线）

| 状态 | 上限 | 消耗来源 | 恢复来源 |
|------|------|---------|---------|
| **生命 Health** | 100 | 实体攻击、跌落、环境伤害 | 杏仁水 +15、医疗包 +40、安全层休息 |
| **理智 Sanity** | 100 | 层级基础侵蚀 + 实体目击 + 黑暗 + 惊吓事件 | 杏仁水 +25、光亮处休息 +8/次、安全层环境 +1/回合 |
| **体力 Stamina** | 100 | 移动 1、奔跑 2/格、战斗 20、搜索 2 | 站立回复 +2/回合、休息 +25、皇家口粮 +20 |

**理智系统（核心特色，完整规格）**：

| 阶段 | 区间 | 表现 | 需要的内容资产 |
|------|------|------|--------------|
| 平静 | >50 | 正常 | — |
| 不安 | 30-50 | 轻度幻觉：错误的声响文字、地图闪现假实体 | 幻觉文字库（30+ 条）、假实体闪现 |
| 恐惧 | 15-30 | 屏幕噪点、色彩失真、声音扭曲、假脚步声 | 视觉滤镜层、音频失真层、脚步音效 |
| 崩溃 | <15 | 随机失控行动、部分回合无法操作、理智流失加速 | 失控行为表、恐慌 UI |
| 同化 | 0 | **"被后室同化"死亡**（与 HP 归零双结局） | 同化死亡演出 |

**来源明细**：层级 DNA `sanDrain`（每回合基础侵蚀：Level 0 = 0.05，Level -1 = 0.5）+ 实体 LOS 内目击 -5/回合 + 黑暗 -0.2/回合 + 随机压力事件 -2 + set piece 惊吓 -8（一次性）。

### 3.3 感知与潜行（v0.2 新增——三通道模型）

1. **光线通道**：光照决定玩家视野半径与实体行为。Smiler 在黑暗中出现、光照下遁形；Duller 相反（光照吸引）；暗处玩家视野半径减半。
2. **声音通道**：奔跑/战斗/开关门产生噪音等级（1-3），听觉型实体（Hound）在噪音 3 格内被吸引；蹲行/静止把噪音降到 0。
3. **视线通道**：直线视线 + 距离衰减；Skin-stealer 仅在玩家执行"查看"时可见；Watcher 对视即侵蚀理智。

**玩家工具**：手电（可开关、电池消耗）、蹲行、静止、投掷物（制造声源引开实体）。

### 3.4 战斗（有限战斗）

- 默认无武器；临时武器（撬棍、铁管）伤害 20-30；徒手 5-10。
- 战斗消耗体力 20/次；失败代价高 → 战斗是最后手段，潜行与逃跑优先。
- 实体属性：HP / 伤害 / 速度 / 感知通道 / 行为模式（被动游荡、好奇跟随、主动猎杀、伏击）。

### 3.5 物品经济

| 物品 | 效果 | 稀缺性 |
|------|------|--------|
| 杏仁水 | 理智 +25 / 生命 +15 | 常见（危险层更少） |
| 皇家口粮 | 体力 +20 | 稀有 |
| 医疗包 | 生命 +40 | 稀有 |
| 电池 | 手电续航 | 常见 |
| 手电 | 视野/驱退部分实体 | 稀有 |
| 撬棍 | 战斗 + 撬门 | 稀有 |

### 3.6 死亡与留存（v0.2 新增——闭环核心）

- **永久死亡**：HP 归零（物理终结）/ 理智归零（被同化）→ 本轮结束。
- **行记 Codex（跨轮持久）**：已发现层级、收集的文档与物品图鉴、个人笔记、死亡记录——**存档独立于角色**，永久保存。
- 死亡结算页：存活回合数、发现层级数、死因、本轮新增 Codex 条目（"你记住了……"）。
- 留存钩子：Codex 完整度是玩家唯一的"长期目标"——探索是为了把知识带回去。

### 3.7 探索日志（保留 v1.0 + 落点）

- 自动记录：到达层级（编号/名称/难度/首次时间）、发现出口、收集文档。
- 手动：笔记、标记重要位置。
- **技术落点**：日志 = Codex 的一部分，跨轮持久（见 §6.3 世界持久化）。

### 3.8 收藏陈列室（替代基地建设）

- 安全层（Level 1/3999）设固定陈列房间：展示架摆放收集品（杏仁水空瓶、实体残骸、文档拓片）。
- 成本极低（静态场景 + 简单摆放 UI），服务"收藏家/建筑师"两类玩家的 1.0 需求。
- 完整建造系统 → DLC 或 UGC 编辑器能力（见 §8）。

## 4. 内容架构（v0.2 核心修订）

### 4.1 三层内容模型（替代"4000 手作层级"）

| 层级 | 数量（1.0） | 作者方式 | 成本/层 | 质量标准 |
|------|------------|---------|---------|---------|
| **A 手工核心层** | 30-40 | 完全手工 + 定制 set piece + 专属音频 | 20-40 人日 | 博物馆级，可被反复谈论 |
| **B 策展生成层** | 200-300 | 手工调优 DNA 模板 × 程序化生成 + 人工抽查 | 2-5 人日 | 稳定、符合美学、有记忆点 |
| **C 野性生成层** | 无限 | DNA 模板自动变异生成 | 0.1-0.5 人日 | "无尽回廊"填充物 |

- 1.0 营销叙事："**40 个手工奇迹 + 无尽生成的世界 + 社区共创**"。
- 月度"策展掉落"：社区投票最高的 C 类升级为 B 类，形成内容飞轮。
- 首个 1.0 批次：A 类含 Level 0-11、Level 37、Level 3999、Level -1、Level 0.1 等 Fandom 经典层。

### 4.2 层级 DNA v0.2（与 v1.0 的差异：加入 set piece 与内容锚点）

```
层级DNA = {
  标识: { id, 编号/代号, 分类(普通/子/隐秘/负数) },
  生存: { 难度Class 0-5, 基础理智侵蚀, 光照等级 },
  地形: { 环境模板, 网格尺寸, 空间规则(欧几里得/循环/非欧) },
  美学: { 色彩方案, 核类风格(怪核/梦核/池核/伤核/商业核), 光照方案 },
  实体: [ { 类型, 密度, 攻击性 } ],
  资源: { 物品表, 丰富度 0-100 },
  内容: { 1-5个 setPieces(文字/怪诞房间/孤物/尸体/壁画/祭坛) },   ← v0.2 新增
  音频: { 环境底噪, 突发音效, 静默事件 },                          ← v0.2 新增
  出口: [ { 目标层级, 方式(卡出/门/梯/电梯/按钮), 隐藏度, 危险度 } ]
}
```

**铁律：程序化只生成"背景板"，恐怖由 set piece 负责。** 完整 JSON Schema 见 `schemas/level-dna.schema.json`，示例数据见 `data/levels/`。

### 4.3 层级图（出口网络）

- 出口不是树，是**有向图**：每层 1-3 个出口，含"危险过渡"（通向更难层级的陷阱出口）。
- 图结构保证：从 Level 0 可达全部 A 类层级；C 类层级的出口随机指向同难度带。
- 玩家日志记录已探索的出口 → "回家路线"（安全层锚点）是玩家自己发现并记住的。

### 4.4 模块化资产库（沿用 v1.0 框架）

- 基础模块：地板/墙壁/天花板（各 30-50 种，按 DNA 墙地风格选择）
- 结构模块：房间 100+、走廊 50+、楼梯、电梯、门
- 装饰模块：家具 200+、照明 50+、杂物 100+
- 特殊模块：实体 50+、交互物 30+、**set piece 组件库 200+（v0.2 新增立项）**

### 4.5 玩家类型与内容投放（v0.2 更新）

| 玩家类型 | 乐趣来源 | 1.0 支撑 |
|---------|---------|---------|
| 探索者 | 发现层级、绘制出口图 | A+B 类层级 + 日志地图 |
| 收藏家 | 收集物品/文档/实体记录 | Codex 图鉴 + 陈列室 |
| 生存狂 | 挑战危险层、最长存活 | 难度分级 + 排行榜（可选） |
| 故事家 | 拼凑后室历史 | set piece 环境叙事 + 文档 |
| 建筑师 | ~~建基地~~ 布置陈列室 | 收藏陈列室（v0.2 调整） |

## 5. 美学与氛围

### 5.1 视觉（沿用 v1.0）

- 阈限空间美学：泛黄荧光灯、潮湿地毯、发霉墙纸；冷色荧光主光 + 局部暖色点缀。
- 主色调：黄/绿/米色，低饱和；故障效果（噪点、闪烁、几何扭曲）与理智值联动（恐惧阶段增强）。
- 核类美学维度（怪核/梦核/池核/伤核/商业核）写入 DNA，指导资产选择与光照方案。

### 5.2 音频（v0.2 升格为一等公民）

- **程序化音频管线**：Wwise 随机容器 + 程序化底噪合成——1 名音频设计师 + 系统生成，覆盖数千层级的音频需求。
- **"突然的寂静"设计原语**：audio ducking 静默切层，写入 DNA（`soundscape` 字段），后室最便宜的恐怖手段。
- 三层音频结构：环境底噪（层级 DNA）→ 突发音效（事件驱动）→ 音乐（仅安全层/特殊事件）。
- 理智联动：恐惧阶段音频音高漂移 + 相位失真 + 假脚步声（幻觉层）。
- 3D 空间音频：脚步方向感、墙体后刮擦声——恐怖的核心载体。

## 6. 技术方案（v0.2 关键补全）

### 6.1 工具链（沿用 v1.0）

UE5 + Blender/Maya + Meshy/Tripo/混元 3D（AI 建模）+ Midjourney/SD（概念）+ Perforce + UE5 PCG Framework。

### 6.2 程序化生成架构（v0.2 修正：两级生成）

```
层级请求
  → 读取 DNA（含 setPieces 声明）
  → L1 拓扑生成：房间/走廊图 + 空间规则（循环/非欧）+ 出口图（确定性种子）
  → L2 细节生成：PCG 填充装饰模块 + 放置实体/物品 + 光照方案
  → SetPiece 锚定：把手工内容放置到拓扑关键点（v0.2 新增）
  → 校验：可达性 BFS、实体密度、无死锁
  → 输出可玩关卡
```

> v1.0 将 PCG 视为"从零生成整个层级"；v0.2 明确 **PCG 负责密度填充，拓扑与锚点由 DNA + 手工 set piece 决定**——这是质量与规模的平衡点。

### 6.3 世界持久化（v0.2 新增——隐藏大功能）

- **确定性生成**：`层级ID + 轮次种子 → 布局`（mulberry32 PRNG）。同一种子永远生成同一层级。
- **存档结构**：`(层级ID, 种子, delta记录)` 三元组——玩家修改（取走物品、写的字、陈列）存 delta，重启后世界仍在。
- Codex（跨轮持久）与角色存档分离。
- **技术原型将直接实现**：确定性生成 + 种子存档（见 `proto/`）。

### 6.4 性能与 QA（v0.2 补全）

- 分层加载：仅加载当前层级；实例化渲染（ISM）+ LOD + 动态资源卸载（沿用 v1.0）。
- **生成内容冒烟测试**：CI 批量生成 1000 种子 × 层级，验证可达性/密度/死锁（原型 `proto/test.js` 内置此逻辑）。
- **Telemetry**：层级卡死率、实体卡墙率、掉入虚空率 → 回写 DNA 模板。

## 9. 合规与 IP（v0.2 新增 ⚠️）

1. **Fandom wiki = CC BY-SA 3.0**：商业衍生必须署名；衍生作品同许可发布。
2. 立项即咨询法务；游戏内置**创作署名页**（主要参考条目与作者）。
3. UGC 许可策略（双许可 or 默认 BY-SA）由法务确认后写入 EULA。
4. 游戏内文档**原创改写**，不直接使用 wiki 原文；层级/实体命名保留 Fandom 约定（属于公共知识体系）。
5. 详细风险与对策见 `docs/planning/risk-register.md`。

## 11. 总结

v0.2 的关键转变：**从"造 4000 块砖"到"设计一套让世界自行运转的法则 + 手工锻造 40 块里程碑级的砖"**。

- 三层内容模型让"无尽回廊"从营销数字变成可执行工程；
